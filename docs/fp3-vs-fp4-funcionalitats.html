Resum
FP3 té sistema madur i complet, però base tècnica obsoleta (L8, Blade manual) difícil de mantenir i ampliar
FP4 guanya 3 funcionalitats noves (perfils flexibles, preguntes events, notícies) i una base moderna molt més àgil
Prioritat alta Notificacions (push/Telegram), estadístiques i importació de castellers per arribar a paritat funcional
Prioritat baixa 2FA, pantalla pública, multi-events i rondes (menys crítiques per a la majoria de colles)
