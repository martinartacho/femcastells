Estratègia de migració recomanada

1
Ampliar castellers FP4 Afegir els camps que manquen: num_soci, address, gender, national_id etc. Fer-ho abans de migrar, no després.
2
Script ETL per colla Artisan command php artisan fp3:import {colla_shortname} que llegeixi la BD FP3 i insereixi a FP4, guardant la correspondència d'IDs en una taula temporal.
3
Transformacions crítiques Status assistència: 1→ok, 2→nok, 3/null→unknown. Country: text → ISO 2. Float mesures → integer. options JSON attendance → event_answers si cal.
4
Validació per colla Comptar registres abans/després. Deixar que la colla validi les seves dades a FP4 durant un període paral·lel abans de donar de baixa FP3.
5
Dades sensibles DNI/NIE i tokens TOTP s'han d'eliminar de FP3 o migrar amb xifrat. Consultar RGPD si la colla és a la UE.
